# Simple Hospital Management System

A C# console application that manages patients across hospital wards using arrays, classes, and menu-driven interaction.

## Overview

This project simulates a small hospital ward system. It allows users to add patients to wards, check ward capacity, and display all patients currently stored in the system.

## Features

- Adds patients with name, age, and condition details
- Stores patients in ward-based array positions
- Tracks the number of patients in each ward
- Prevents users from adding patients to full wards
- Displays all wards and their patients
- Uses a simple menu-driven console interface

## Technologies Used

- C#
- .NET 9
- Console application

## How to Run

```bash
dotnet run
```

## Example Use Case

This application can be used to demonstrate basic patient allocation logic for a small hospital or clinic scenario.
